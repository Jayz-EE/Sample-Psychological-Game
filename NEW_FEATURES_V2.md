# Village of Ashes v2.0 - New Interactive Features

## 🎮 What's New

Version 2.0 adds comprehensive player interaction features, making the game fully playable with:
- **Player Actions** - Talk to NPCs, investigate, spread rumors
- **Village Discussions** - See simulated council conversations
- **Investigation System** - Analyze NPC behavior and suspicion
- **Interactive Dialogue** - Choose responses when talking to NPCs

---

## 🗣️ Village Discussions Panel

### What It Shows
- **Council Phase Conversations** (7:00 AM - 8:00 AM)
- NPCs discussing recent events
- Accusations and suspicions
- Evidence discussions

### When Active
- Automatically displays during Village Council phase
- Shows simulated NPC conversations
- Updates based on game events (deaths, evidence, etc.)

### Example Discussions
```
Edgar Hollow says:
"We need to discuss what happened last night..."

Clara Hollow says:
"I found some suspicious evidence near the village center."

Victor Crowe says:
"Someone has been acting very strange lately..."
```

## 🎭 Player Actions Panel

### 1. Talk to NPCs

**How to Use:**
1. Select an NPC from the dropdown
2. Click "Start Conversation"
3. Read their dialogue
4. Choose a response option

**Response Options:**
- **"Tell me about yourself"** - Builds trust (+5 trust)
- **"Have you noticed anything suspicious?"** - Increases suspicion (+5 suspicion)
- **"Goodbye"** - Neutral exit

**Effects:**
- Changes trust/suspicion levels
- Affects future interactions
- May reveal information

**API Endpoint:** `GET /api/dialogue/npc/{npcId}`

---

### 2. Investigate NPCs

**How to Use:**
1. Select an NPC to investigate
2. Click "Investigate Behavior"
3. View detailed analysis

**What You Learn:**
- **Behavior Pattern:**
  - Activity Level (High/Medium/Low)
  - Consistency (Consistent/Variable)
  - Social Interaction (Frequent/Occasional/Rare)

- **Suspicious Findings:**
  - Unusual night movements
  - Inconsistent alibis
  - Strange behavior patterns
  - Evidence connections

**Use Cases:**
- **Detective Role:** Identify the Butcher
- **All Roles:** Assess threats and allies
- **Strategic:** Plan accusations or alliances

**API Endpoints:**
- `GET /api/investigation/behavior/{npcId}`
- `GET /api/investigation/suspicious/{npcId}`

---

### 3. Spread Rumors

**How to Use:**
1. Select a target NPC
2. Enter rumor text
3. Click "Spread Rumor"

**Examples:**
- "I saw them near the murder scene"
- "They've been acting very suspicious"
- "I heard they're planning something"

**Effects:**
- Increases suspicion toward target
- Spreads through NPC network
- Can influence council votes
- May backfire if proven false

**Strategic Uses:**
- **Butcher:** Frame innocent NPCs
- **Detective:** Test reactions
- **All Roles:** Manipulate social dynamics

## 🔍 Investigation Summary Panel

### Overview Statistics
- **Total Evidence** - Physical clues found
- **Total Rumors** - Circulating gossip
- **Observations** - NPC-recorded facts

### Most Suspicious NPCs
Visual suspicion bars showing:
- NPC name
- Average suspicion level (0-100%)
- Red gradient bar

**Interpretation:**
- **80-100%:** Highly suspected, likely to be accused
- **60-79%:** Moderately suspected
- **40-59%:** Some suspicion
- **0-39%:** Low suspicion

### Most Trusted NPCs
Visual trust bars showing:
- NPC name
- Average trust level (0-100%)
- Green gradient bar

**Interpretation:**
- **80-100%:** Highly trusted, strong ally
- **60-79%:** Trusted
- **40-59%:** Neutral
- **0-39%:** Distrusted

**API Endpoint:** `GET /api/investigation/summary`

## 🎯 How to Play with New Features

### Early Game (Day 1-2)
1. **Talk to all NPCs** - Build initial relationships
2. **Investigate suspicious NPCs** - Gather baseline behavior
3. **Avoid spreading rumors** - Don't draw attention

### Mid Game (Day 3-5)
1. **Focus investigations** - Target most suspicious NPCs
2. **Strategic conversations** - Build alliances with trusted NPCs
3. **Spread tactical rumors** - Influence council discussions

### Late Game (Day 6+)
1. **Confirm suspicions** - Final investigations
2. **Rally allies** - Talk to trusted NPCs
3. **Decisive rumors** - Push for specific accusations

## 📊 Understanding the Data

### Suspicion Levels
- **Generated by:** NPC observations, evidence, rumors
- **Affects:** Council votes, accusations, alliances
- **Visible in:** Investigation Summary, NPC cards

### Trust Levels
- **Generated by:** Positive interactions, helping behavior
- **Affects:** Dialogue options, protection, information sharing
- **Visible in:** Investigation Summary

### Behavior Patterns
- **Tracked by:** Night actions, day movements, interactions
- **Used for:** Role prediction, suspicion calculation
- **Visible in:** Investigation results

## 🐛 Troubleshooting

### Actions Not Working
- **Check:** Server is running on port 5000
- **Check:** Browser console (F12) for errors
- **Try:** Hard refresh (Ctrl+F5)

### NPCs Not in Dropdowns
- **Check:** Game has been started (click "New Game")
- **Check:** NPCs are alive (check Villagers panel)
- **Try:** Click "Refresh" button

### Village Discussions Empty
- **Check:** Current phase is Village Council (7:00 AM - 8:00 AM)
- **Check:** Game is past Day 1
- **Try:** Advance time to council phase

### Investigation Summary Not Loading
- **Check:** API endpoint is accessible
- **Try:** Open browser console and look for errors
- **Try:** Restart server
